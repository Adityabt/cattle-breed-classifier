About This Project

This AI-powered system identifies cattle breeds using deep learning. It is built on a ResNet50 backbone enhanced with Attention-Guided Part Network (AGPN) and Multi-View Feature Fusion (MVFF).

The model focuses on key visual features such as coat patterns, facial structure, and body shape to classify breeds accurately.

Along with predictions, the system provides confidence scores and Grad-CAM attention maps to explain model decisions.

This project demonstrates the application of computer vision in agriculture and livestock management.
